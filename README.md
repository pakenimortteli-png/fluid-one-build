Fluid One is an android launcher made to be customized. You can apply icon packs, use Fluid One default icons like dark, light, accent or glass. You can add widgets and customize them, you can change the page transition and you can change the layout.
Fluid One has a layout made out of glass and blur elements.
Fluid One is constantly being updated, so if something doesn't work, it will be fixed in the future.
If you find any bugs, report them to jstudios@duck.com.
